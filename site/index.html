Four things, all of them yours

§ 01 — what it does

No cloud, no seats, no monthly bill. It's one program on your machine that does the parts of design that are tedious and repeatable, and leaves the rest to you.

◈
01 · AKMON

Colours from a sentence

Type what you want — "calm banking app", "loud poster" — and it builds the whole palette: background, text, accents, borders, states. Contrast is checked while it works, not after.

⊞
02 · CANVAS

Layouts that stay tidy

Drop blocks on a canvas and everything keeps its alignment and spacing. Pages, links between pages, and an HTML export when you're done — viewable full-screen before you use it anywhere.

✦
03 · MERKHET

A review you can argue with

Point it at a design and it lists what's weak — contrast too low, spacing too tight, too many colours fighting — each with a specific fix it will make, or not, at your word. It never claims a repair it hasn't measured twice.

▤
04 · TRENDS

Places to start

1,750 directions with colours, type and layout rules already paired, each with a recipe you can pull apart. Browse them, search them, steal one, keep going.

What it isn't

§ 03 — the catch

Worth saying out loud, because most tools avoid it.

  • No AINothing generates your work and nothing sends it anywhere to be generated for you. Rules and measurements instead — so the same input gives the same answer every time, and you can look up why.
  • No account, no telemetryThe app runs offline and keeps its files on your disk. No fonts, no images, no analytics, nothing that could count you reading it. The only call this page can make is an anonymous read of a public release list, and it makes it twice at most, once: no token, no cookie, nothing beyond the IP any request carries.
  • No subscriptionIt's free, and it isn't free "while it's in beta". There's no key, no seat count, no license screen, nothing that stops working in a year.
  • Not a Figma replacementIt won't do multiplayer, prototypes or plugins. It's good at the four things above and quiet about everything else.
  • Nothing hard-wiredThe markup contains no download URLs at all. The cards read the newest published release when there is one to read, and stay plainly inert when the repo is private, empty, or unreachable — so a stale page can't offer you a file that was never uploaded. How to get it has the details.
  • Even the portrait is by ruleThe head above is the app's own mark measured on a 72-cell grid and set in ten characters, darkest to @. The strips in the screens section came out of the same kind of rule. tools/ascii-art.py: arithmetic, a font metric, nothing trained.

§ 04 — availability

Pick your system: each card hands out the matching file from the newest published release, and every release ever published is listed underneath with everything on it. When there is nothing to read, the page says so in words instead of pointing you at something that isn't there.

03 Linux you

Any recent distro: an AppImage that runs, and a .deb for the ones that want a package.

not posted yet

checking for a published release…

Nothing here is typed by hand. This file names one repo, the list below and the cards above read whatever that repo has actually published, and a deploy overwrites the name with the repo it ran from — so publishing a release is the whole maintenance routine, and there is no number to remember. A repo that goes private, or a release that was never published, or a network that won't answer all leave the cards as they are: no link invented, no button that goes nowhere. macOS builds aren't signed with a developer certificate, so on the first launch right-click the app and choose Open. Everything else installs normally.
